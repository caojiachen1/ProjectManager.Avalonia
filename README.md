# ProjectManager.Avalonia

A cross-platform rewrite of [ProjectManager](https://github.com/caojiachen1/ProjectManager) using Avalonia UI.

The original project is a WPF-based desktop application targeting .NET 9 and Windows only. This rewrite replaces WPF with Avalonia UI 12 on .NET 10, bringing support to Windows, Linux, and macOS.

## Build & Run

```bash
dotnet restore
dotnet build
dotnet run --project ProjectManager.Avalonia.Desktop
```
